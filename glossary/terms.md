# 术语表（中英对照）

用法：笔记里出现的术语，写法必须和这里一致；先加表，再引用。释义先给一句话，听课后补出处周次与课程原话。

首批是课程通用术语（W1 之前的底子），听完对应周再回补“课程怎么讲”。

| English | 中文 | 一句话 | 周次 |
|---|---|---|---|
| corpus / corpora | 语料库 | 按原则采集、可机器检索的语言数据集合 | W1 |
| representativeness | 代表性 | 语料在多大程度上代表目标语言变体 | W1 |
| balance | 平衡性 | 各语域 / 文本类型的配比是否合理 | W1 |
| token | 词次 | 文本中每个词形实例（重复计） | W1 |
| type | 词型 | 不同的词形（去重后） | W1 |
| hapax legomenon | 一次词 | 全库只出现一次的词 | W1 |
| annotation | 标注 | 叠加在原文上的语言信息层 | W1 |
| POS tagging | 词性标注 | 为每个 token 标词性 | W2 |
| lemmatisation | 词形还原 | 把屈折形式归并到 lemma | W2 |
| concordance | 索引 / 语境共现 | 检索词连同左右语境逐行列出 | W1 |
| KWIC | 关键词居中 | key word in context，检索词居中的语境行 | W1 |
| node (word) | 节点词 | 被检索的那个词 | W2 |
| span | 跨距 | 节点词左右各取几个词 | W2 |
| collocation | 搭配 | 显著高频共现的词组合 | W2 |
| collocate | 搭配词 | 与节点词共现的词 | W2 |
| mutual information (MI) | 互信息 | 共现强度指标，偏向低频稀有搭配 | W2 |
| log-likelihood | 对数似然 | 共现显著性统计量（G²） | W2 |
| logDice | logDice | 搭配强度指标，对频率较稳健、可跨语料比 | W2 |
| keyness | 关键性 | 目标语料相对参照语料的频率突出程度 | W2 |
| keyword | 关键词 | 关键性高的词 | W2 |
| effect size | 效应量 | 差异的“大小”，与显著性分开报 | W2 |
| register | 语域 | 由使用情境决定的语言变体 | W3 |
| learner corpus | 学习者语料库 | 二语学习者产出构成的语料 | W7 |
| metadata | 元数据 | 文本的说话人 / 年份 / 体裁等属性 | W5 |
