# 结课小项目

目标不是做研究，是**证明这条链路走得通**：选语料 → 提问 → 检索/统计 → 一句能站得住的结论。

## 选题卡（填完再动手）

| 项 | 内容 |
|---|---|
| 研究问题（一句疑问句） |  |
| 语料（用哪个、为什么它能回答这个问题） |  |
| 参照语料（若做关键词） |  |
| 方法（concordance / collocation / keyness） |  |
| 预期产出（表 / 图 / 一段话） |  |
| 时间盒 |  |

## 产出规格

- 800–1200 字，或 1 页表格 + 300 字说明
- 必须包含：语料说明（规模、来源）、查询串或参数、结果表、结论、局限
- 结论里至少一个数字；没有数字说明还没真正查过

## 常见退化

| 症状 | 说明 |
|---|---|
| 结论 = “X 词出现很多次” | 频率本身不是发现，要跟参照比、跟语境比 |
| 图很漂亮但没参数 | 不可复现，等于没做 |
| 问题太大 | “英语怎么变了”不是八周能答的，缩到具体变体 + 具体检索项 |

## 归档

完成后放 `project/<slug>.md`，并在 [README](../README.md) 里点一句。
