# tools/ — 工具速查

三件套，按课程承诺都会用到。每张卡固定五节：是什么 / 能干什么 / 怎么起 / 我的操作记录 / 坑。

| 工具 | 官网 | 形态 | 用在哪 |
|---|---|---|---|
| [#LancsBox X](lancsbox-x.md) | https://lancsbox.lancs.ac.uk/ | 本地安装（免费） | 全课主工具：KWIC、GraphColl、关键词、自建语料 |
| [CQPweb](cqpweb.md) | https://cqpweb.lancs.ac.uk/ | 网页（需账号） | 公用大语料上的查询与跨语料比较 |
| [BNCLab](bnclab.md) | https://bnclab.lancs.ac.uk/ | 网页 | BNC1994 vs BNC2014 的社会语言学研究 |

## 记录纪律

- “我的操作记录”比“功能介绍”值钱：参数、样本量、截图三样齐全，半年后还能复现
- 任何新坑都记到对应卡片的“坑”表，别只留在脑子里
- 三张卡的链接都实测过；新增链接必须自己先打开确认
