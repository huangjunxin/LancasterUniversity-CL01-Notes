# CQPweb

官网：https://cqpweb.lancs.ac.uk/ （2026-10-29 核实可访问）

## 是什么

CQP（Corpus Query Processor）的网页前端，兰卡斯特服务器版由 Andrew Hardie 维护。**要用需注册账号**（首页有 Create account）。语料托管在服务器上，不用自己下载。

## 能干什么

- 在公用大语料上直接做查询、搭配、关键词比较
- 用 CQP 语法写比界面按钮更精细的查询（例如按词性、按元数据限制语域）
- 结果可导出，方便复核

## 怎么起

1. 首页 Create account 注册 → 登录
2. 选语料 → Simple query（或 CQP syntax）→ 看 concordance / collocation / keyness
3. 需要跨语料比较时，注意两边的 token 总数与元数据口径
