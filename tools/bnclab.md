# BNCLab

官网：https://bnclab.lancs.ac.uk/ （2026-10-29 核实可访问）

## 是什么

兰卡斯特做的 BNC 对比分析界面，用来把 **BNC1994** 和 **BNC2014（Spoken）** 放在一起看，第 5 周（sociolinguistics）主要工具。

注意：站点首页打开就是应用界面，没有静态说明页 —— 用法以课程演示为准，别凭猜测写结论。

## 能干什么

- 同一检索项在 1994 / 2014 两个时间点的频率对比
- 按社会变量（性别、年龄、地域等）切分观察
- 快速判断某个变化是趋势还是噪声

## 怎么起

1. 打开官网，直接进应用
2. 输入检索项 → 选对比维度 → 读图表
3. 记下检索项、口径、样本量，否则数字无法复核
