## 怎么用（配合 agent）

- 听完一周 → 打开对应 `weeks/NN-*.md`，把"笔记 / 工具实操 / 练习 / 疑问"四块填掉，同时把看板状态改成"已整理"
- 卡住某个工具 → 查 [tools/](tools/README.md)，没有就补一条实操记录（这是本仓库最值钱的部分）
- 术语搞不清 → 先查 [glossary/terms.md](glossary/terms.md)，没有就加一行
- 想验证一个统计结论 → 查 [reference/methods-cheatsheet.md](reference/methods-cheatsheet.md)，别凭印象
- 准备结课 → [project/README.md](project/README.md) 有选题与产出模板

语料原文与下载包不入库（体量与授权），只记录来源与处理参数，见 [corpora/README.md](corpora/README.md)。
