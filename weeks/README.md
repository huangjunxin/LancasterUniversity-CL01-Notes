八个文件对应官方八周大纲，**只填内容，不要改名**（README 看板与互链都指向这些文件名）。

## 填法

1. 听课前：扫一眼“本周目标”，改成你真正想解决的问题
2. 听课中：只记操作参数和没听懂的点，别抄字幕
3. 听课后：补“笔记”与“结论”，“工具实操”要填到别人能照着复现
4. 对照 [CURRICULUM.md](../CURRICULUM.md) 第 4 节的四条验收线，够了就把 README 看板改成“已整理”

新建周笔记用 [templates/weekly-note.md](../templates/weekly-note.md)。
