## 1. 频率

原始频数不能直接比，语料大小不同。

```
relative frequency (per million) = f / N × 1,000,000
```

- f = 检索项频数，N = 该语料 token 总数
- 比较前先确认两边的 N 是**同一口径**（是否含标点、是否按 token 而非 type 计）
- 报告写法：f = 123, N = 10,000,000 → 12.3 per million

## 2. 搭配

三个基本量：node（节点词）、span（跨距，常见 ±4 或 ±5）、collocate（搭配词）。

| 指标 | 公式 | 特点 |
|---|---|---|
| MI | `log2(O / E)`，其中 `E = R1 × C1 / N` | 偏高低频稀有搭配；大语料里高频词 MI 常偏低 |
| log-likelihood (G²) | `2 × Σ O × ln(O / E)` | 对高频敏感，适合判“是否显著”，不适合判“强度” |
| logDice | `14 + log2(2 × f_xy / (f_x + f_y))` | 取值上限 14；对单个词频依赖小，跨语料较可比 |

- O = 实际共现次数；E = 期望共现次数；R1 = 节点词总频；C1 = 搭配词总频；N = 语料总量
- 实操：**先按频率筛掉噪声（如 f_xy ≥ 3 或 5），再用 logDice / MI 排序，另报 G² 与频数**

## 3. 关键词（keyness）

目标语料 vs 参照语料（reference corpus）的频率对比。

```
log ratio = log2( (f_t / N_t) / (f_r / N_r) )
```

- f_t / N_t：目标语料相对频率；f_r / N_r：参照语料相对频率
- 关键词表是**相对参照语料**才成立的，同一个目标语料换参照，关键词会变
- 报告：keyness 统计量 + log ratio（效应量）+ 两边原始频数，缺一不可

## 4. 三个常见坑

| 坑 | 表现 | 修法 |
|---|---|---|
| 没归一化 | 拿原始频数说“A 语料用得更多” | 先换 per million |
| 只报显著性 | “p < 0.001”就当结论 | 加效应量；样本大到一定程度，微小差异也显著 |
| 参照语料随意选 | 关键词表看着很漂亮 | 参照语料要能代表“背景语言”，并在报告里写明 |
